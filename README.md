## Selection and precedence

The **25 November 2026** inventory checked live version lists for all **88 Mishneh Torah titles in the public Sefaria export index**. Only versions with “Mandelstam” in the title and actual language `de` were selected. One DeepL machine-translated derivative was excluded. No English or Hebrew comparison edition was imported as a German Mandelstamm main text.

All twelve German Sefaria editions are already represented in Safran. The complete Safran file therefore remains authoritative for each overlapping title, including the corrected Kings and Wars. No nonempty halakhah in these Sefaria versions is missing or empty in Safran. No silent mixed edition was produced.

There are **425 differing segment pairs**, measured by exact strings including HTML and whitespace. This is not a count of substantive variants or verified errors. Both source texts remain traceable.

## Kings and Wars corrections

All twelve chapters were read; **23 selected typographical, spacing, capitalization and grammatical corrections** were applied. One of these is a source-checked missing negation in **8:9**, “ihren Götzendienst **nicht** aufgeben”, explicitly identified as a meaning-changing correction. Every change has a reference, before/after text and reason. Other possible citation and wording problems are recorded as open review items.

See [correction history](corrections/kings-and-wars.json). Historical spellings and existing editorial supplements remain intact. The corrections are also committed in Safran; this collection exports that commit.

## Files

- `data/`: 39 main files with source metadata and text structure; Safran always takes precedence.
- `sources/sefaria/`: twelve unchanged German comparison snapshots and a manifest with retrieval date, URLs, version metadata and hashes. They are not a second coequal main edition.
- `comparison/safran-sefaria.json`: source selection, differing references with text hashes and checks for nonempty Sefaria-only text.
- `corrections/kings-and-wars.json`: all 23 changes, primary-text comparison for 8:9 and open review items.
- `links/`: 25 existing Safran reference files, not full texts of linked works.
- `portraits/mandelstamm.jpg`: unchanged Safran portrait.
- `manifest.json`: pinned Safran commit and source subdirectory (`app/`), selection, counts and SHA-256 hashes.
- `scripts/`: synchronization, standalone validation and explicit refresh of Sefaria snapshots.

`text` is organized by chapter and halakhah, with 1-based list positions. All 174 empty slots among 6,470 segment slots are retained. Inherited `en`/`English` language fields technically identify German content; the manifest records actual language `de`. HTML formatting and footnotes are preserved.

## Provenance and scope

The source metadata identifies Mandelstamm’s St. Petersburg 1851 edition, catalogued in the [Freimann collection](https://sammlungen.ub.uni-frankfurt.de/freimann/content/titleinfo/8319354). Several digital editions explicitly acknowledge corrections, added missing passages and explanatory brackets by Igor Itkin; other Safran versions identify eScriptorium transcription. These distinctions remain in the metadata.

This collection includes all German Mandelstamm texts found in the checked Safran/Sefaria inventory, not all halakhot of the entire Mishneh Torah. Sefaria downloads follow its [official export documentation](https://github.com/Sefaria/Sefaria-Export). Raw OCR and facsimiles are not included. Structural completeness does not establish complete collation against print.

## Reproduce and validate

Python 3.9+; `curl` for an explicit internet refresh:

```sh
python3 scripts/validate.py
python3 scripts/sync_safran.py /path/to/Safran
# Only to deliberately refresh archived Sefaria snapshots:
python3 scripts/fetch_sefaria.py
python3 scripts/sync_safran.py /path/to/Safran
```

Normal synchronization reuses local Sefaria snapshots and committed Safran inputs. Validation checks hashes, precedence, counts, differing segments and reversible correction history. If Sefaria later supplies additional nonempty text for a local title, synchronization stops for review rather than silently discarding it.
